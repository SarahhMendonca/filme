# filme# 🎬 Landing Page — Filme: Corra! (*Get Out*)

Uma página web temática desenvolvida para apresentar informações, sinopse e detalhes sobre o aclamado filme de suspense psicológico **Corra!** (*Get Out*), dirigido por Jordan Peele.

---

## 📌 Sobre o Projeto

O objetivo deste projeto é criar uma interface simples, intuitiva e atraente em HTML para fãs de cinema. A página reúne os principais destaques da obra, permitindo uma navegação rápida pelas informações técnicas e visuais do filme.

### 🎬 Sobre o Filme
* **Título Original:** Get Out
* **Direção:** Jordan Peele
* **Gênero:** Terror Psicológico
* **Ano de Lançamento:** 2017
---

- [x] **Mídia:** Capa do Filme.
